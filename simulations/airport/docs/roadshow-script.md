# 路演讲解提纲

本目录的 `media/airport-collaboration-roadshow.mp4` 是一版 58 秒横屏片，字幕顺序对应五个重点：

1. **机器狗先到场**：三只 DOG 并行走 RMF 路线，页面标出实际运动速度。
2. **无人机分层复核**：对应 DOG 到点后才放行 UAV，展示 6 / 7 / 8 米高度差异。
3. **共享运输运力**：两台 AMR 服务三处工单，未分配到车辆的区域显示等待原因。
4. **双方到位交接**：DOG 和 AMR 实测静止到位，连续驻留后才确认模拟工单，并释放运力服务下一处区域。
5. **闭环归档**：12 个 RMF 任务、9 张相机证据和 8 台设备归位。

演示时先说明：这是电脑上的 ROS 2 / Gazebo / Open-RMF 仿真；告警是场景注入事件，交接是模拟工单确认，不代表实体机器人、PX4 飞控或 AI 缺陷识别。
